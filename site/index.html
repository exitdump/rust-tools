Install

Up and running in 30 seconds

Download from the cards above, or copy these commands. They install meow; for another tool, change the name.

1

Open PowerShell and download meow into ~\bin:

iwr https://github.com/exitdump/rust-tools/releases/latest/download/meow-windows-x64.zip -OutFile meow.zip
Expand-Archive meow.zip -DestinationPath "$HOME\bin" -Force
2

Add that folder to your PATH (only once):

$p = [Environment]::GetEnvironmentVariable("Path", "User"); [Environment]::SetEnvironmentVariable("Path", "$p;$HOME\bin", "User")
3

Open a new terminal and try it:

meow --help
1

Download and install. On an Intel Mac, use macos-x64 instead of macos-arm64.

curl -fsSL https://github.com/exitdump/rust-tools/releases/latest/download/meow-macos-arm64.tar.gz | tar xz meow
sudo mv meow /usr/local/bin/
2

Try it:

meow --help

Downloaded it in a browser and macOS blocks it? Run xattr -d com.apple.quarantine meow once.

1

Download and install. It's a static binary, so it runs on any distro.

curl -fsSL https://github.com/exitdump/rust-tools/releases/latest/download/meow-linux-x64.tar.gz | tar xz meow
sudo mv meow /usr/local/bin/
2

Try it:

meow --help
1

Already have Rust? Build and install straight from GitHub, on any system:

cargo install --git https://github.com/exitdump/rust-tools meow

No Rust yet? Get it from rustup.rs, or use the ready-made downloads in the other tabs.

Contribute

Build the next tool with us

New to Rust? That's fine. The guide walks you through every step, and CI checks your work on all three systems.

1

Fork & clone

Fork the repo on GitHub, clone it, and run cargo test.

2

Pick a tool

Take a planned tool above, or suggest your own.

3

Build it

Run cargo new tools/name and start from the template in the guide.

4

Open a PR

Push your branch. Once it's merged, it ships for every system automatically.
